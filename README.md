# 📖 LeerCoin ($LER) - Protocolo Proof of Attention

**LeerCoin** es una DApp descentralizada y ultra ligera que recompensa la lectura humana verificada mediante telemetría biomecánica sin necesidad de hardware biométrico ni recolección de datos personales.

---

## 🚀 Características Principales

* 🧠 **Proof of Attention Biomecánico:** Algoritmo en cliente (`detector.js`) que valida scroll natural, pausas de retención e interacción física.
* 🛡️ **Privacidad Absoluta:** Cero registro de correo o bases de datos centralizadas. Los datos residen localmente en el navegador.
* ⚡ **Eficiencia y Cero Gas:** Diseñado para ejecutarse en la red Cardano utilizando pagos agrupados para minimizar costos de red.
* 🧘‍♂️ **Diseño Minimalista:** Interfaz enfocada en la lectura pausada y sin distracciones.
